title: Ecz-Ware (Engineering Design Innovation Project)
description: Ecz-Ware is a wearable that detects scratching in real time using flex sensors and an MPU6050 (accelerometer + gyroscope), processed on a Raspberry Pi Pico / Raspberry Pi 5 pipeline with a trained model for gesture classification. Upon detection, a haptic vibration motor provides subtle feedback to interrupt the itch–scratch cycle. <br> My work was centered around designing the structure of the glove itself, to ensure it was comfortable for users while housing all the components needed, including a Raspberry Pi Pico, haptic motors and any sensors needed. The design changed drastically between iterations, from early concepts where we considered using a pneumatic feedback system, to a later version which used Myoware sEMG sensors to detect muscle movement, to the final version which made use of flex sensors for scratch detection instead.
